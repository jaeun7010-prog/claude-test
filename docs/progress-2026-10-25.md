## 한 일 (사용자 요청)
- 3단계 화면 확인 완료 (사용자).
- **직접 짓기로 돌아가기**: "이 사주에 맞는 다른 소리 보기"·돌림자 추천받기 링크에 정한 이름(`sg`)·지금 고른 한자(`shj`)를 붙이고, 추천받기 결과 화면 맨 위에 "← '서윤' 직접 짓기로 돌아가기"(휴대폰에서는 화면 폭 버튼). 직접 짓기에서 온 경우만 보이고, 돌아가면 고른 한자가 그대로 골라져 있다.
- **4단계**
  - 고르기 화면: 두 자리를 다 고르면 위에 붙는 줄과 고른 조합 점수 아래에 "결과 보기" → `/naming/self/result`.
  - 결과 화면: 이름 카드(이름 뜻 한 줄·점수·4격·글로벌 발음·법적 기준·잠금), 조합 진단(부모 성), 사주 카드, "← 한자 고르기로 돌아가기". 조합은 `loadSelfChoice`(→ `isSelfSelectable`)로 확인.
  - 저장: `saveSelfName`, 저장 후 결과 화면으로 돌아와 "마이페이지에 저장했어요". `filters.source = "self"`·`selfGiven`.
  - 리포트·결제: `from=self`로 `/goods`·`createOrder`가 조합을 확인. 후보에 없는 한자(예: 壻)는 "고른 한자 조합을 확인할 수 없어요".
  - 마이페이지: "직접 지음" 표시, "최신 기준으로 다시 분석"은 고르기 화면(저장한 한자 고른 채로), 리포트 주소에 `from=self`.

## 오후: 확인하며 고친 것 (사용자 요청)
1. **추천받기 저장 안내**: 저장하면 마이페이지로 넘어가던 것을 직접 짓기처럼 결과 화면의 그 카드에 "마이페이지에 저장했어요"(두 번째는 "이미 마이페이지에 저장한 이름이에요"), 순우리말도 같게. 다른 한자 조합을 저장했으면 접힌 목록을 펼쳐 둔다. `components/naming/saved-status.tsx`.
2. **"최신 기준으로 다시 분석" 없앰**: 마이페이지 상세 버튼을 "같은 조건으로 다른 이름 보기"(추천받기·순우리말) / "한자 다시 골라 보기"(직접 지음)로, 안내는 "아래는 저장할 때의 분석 그대로이고, 결제한 리포트도 결제할 때의 내용 그대로 보관됩니다". 화면·PDF·코드 주석에서 "최신 기준·다시 분석·지금 기준" 문구를 찾아 바꿈.
3. **성씨 목록 단순화**: "다른 한자 성씨 보기" 접기와 인구수 표시를 없애고 인구순 한 목록 (1위 기본). `SURNAME_VISIBLE_SHARE` 삭제.
4. **결제 여부 = 같은 아이 + 같은 이름**: `namingChildKey`(성·성씨 한자·생년월일·시각·야자시·출생지·성별). 글자 수·돌림자 등 검색 조건 차이로 잠기지 않는다. 중복 저장·비교 화면 안내는 예전 조건 키 그대로.

## 저녁: 결과 화면에 저장·구매 여부 표시 (사용자 요청)
- "같은 조건으로 다른 이름 보기"로 돌아오면 이미 저장한 이름에도 저장 버튼만 보이던 것. 화면을 열 때 `loadSavedLookup`(같은 아이 + 같은 이름)으로 "✓ 저장한 이름 · 저장한 이름 보기", 리포트를 산 이름은 "리포트 보기 · PDF 다운로드 · 맞춤 굿즈". 추천받기·직접 짓기·순우리말 탭·다른 한자 조합까지, 비로그인은 그대로.
- 중복 저장 확인(`findSavedDuplicate`)도 같은 기준(같은 아이 + 같은 이름)으로 바꿈.
- 확인: 김 2024-05-10 여아 — 金霞潤 저장분이 다른 조건(`glob=1`, 글자 수 상관없음)에서도 ✓, 다른 한자 조합 金河潤 저장 → 펼친 목록 안에 "✓ 마이페이지에 저장했어요", 순우리말 보미 저장 → 다시 열면 ✓. 직접 짓기 결과 全澨潤(리포트 구매): ✓ + 리포트 보기·PDF 다운로드·맞춤 굿즈. 확인하며 저장한 金河潤·보미 2건이 마이페이지에 남아 있다.
