- 성씨 자원오행 논문 인용을 되돌리고 서지를 고쳤다. 한때 지웠던 인용이고, 실제 있는 논문이라는 사용자 정정에 따른 것이다.
- 사용자 결정: 『문화와융합』 논문은 발행 기관 이름 없이 학술지명·권호·연도·쪽수만 적는다.

### 결과 주소 암호화 (커밋 9bce3b9, `lib/naming/url-seal.ts`)
- 입력 조건을 `c=암호문`으로 묶는다 (AES-256-GCM, 키 `NAMING_URL_KEY`, 서버 전용).
- 입력 폼은 서버 액션으로 보내 평문 주소를 거치지 않는다. 예전 평문 주소는 열면 암호화 주소로 옮긴다.
- DB(`filters.qs`, `item_options.qs`)는 평문 그대로다. 키를 바꾸면 예전 암호화 주소만 열리지 않는다.
- 키가 없으면 평문 주소로 동작한다. **지금 `.env.local`에 키가 없어 로컬 주소는 아직 평문이다.**
- 받은 사람이 주소를 열면 화면에 아이 정보가 보이므로, 추천 결과·직접 짓기 결과·한자 고르기 화면에 공유 안내를 넣었다.

### 확인한 것과 못 한 것
- 임시 키로 별도 빌드에서 확인: 두 입력 폼, 예전 주소, 리포트·굿즈 이동, 순우리말 탭. 페이지 이동 주소와 화면 링크에 평문 생년월일 없음.
- 키가 없을 때 개발 서버에서 평문 주소로 정상 동작.
- 일부를 고친 암호 주소로 한자 고르기 화면을 열면 입력 화면으로 돌아감.
- **못 한 것:** 로그인이 필요한 흐름(저장 후 돌아오기, 마이페이지 링크, 결제 후 주문의 평문 조건), 통계 자료가 있을 때의 첫 화면.
