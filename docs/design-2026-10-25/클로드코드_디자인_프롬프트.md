# 이름핏 디자인 적용 프롬프트 (2026-10-25 확정 시안)

## 쓰는 방법

1. 압축 파일을 풀어서 프로젝트 폴더 안에 `docs/design-2026-10-25/` 폴더째 넣으세요.
2. 아래 **1단계** 상자 안의 글을 Claude Code에 붙여넣습니다.
3. 끝나면 화면을 확인하고 → `/clear` → **2단계** → `/clear` → **3단계** 순서로 진행합니다.
4. 각 단계가 끝날 때 Claude Code가 "확인이 필요한 것"을 알려 주면, 그 내용을 채팅으로 가져와 주세요.

- `Main.dc.html` 첫 화면 · `Palette.dc.html` 색과 글꼴 · `Logo.dc.html` 로고
- `Form` 입력 · `Loading` 기다림 · `Result` 결과 · `Report` 리포트 안내 · `Done` 완료 (`.dc.html`)
- `logo-feet.svg` 두 발 발도장 로고 · `favicon.svg` 앱·탭 아이콘

## 3단계 · 이용 흐름 화면 (입력 → 기다림 → 결과 → 리포트 → 완료)

```
docs/design-2026-10-25/의 Form, Loading, Result, Report, Done .dc.html을 참고해서 지금 화면의 겉모습만 바꿔 줘. 기능과 데이터 흐름은 그대로 두고, 1단계 부품을 써.

- 입력: 위쪽 3단계 진행 막대(첫 단계는 완료 표시), 이미 넣은 정보 요약 + "고치기", 양력이 기본값, 도움말은 칸 바로 아래("태어난 곳에 따라 시각을 조금 보정해요"), 아래쪽에 고정된 큰 버튼 "이름 30개 받기", 그 아래 "카드 등록 없이 무료예요". "시각을 몰라요"는 지금 지원하는 경우에만.
- 기다리는 화면: 단계 3개(사주 계산 → 어울리는 한자 찾기 → 점수 매기기) 체크 표시, 진행 막대, 회색 뼈대 카드, 성씨 상식 한 줄("같은 정씨도 鄭(19획)과 丁(2획)은 획수가 달라서 어울리는 이름도 달라요"). 실제 진행 상태를 알 수 없으면 순서대로 보여 주기만.
- 결과: 맨 위 결론 "이 아이에게는 ○(○)과 ○(○)가 필요해요" + 오행 막대 5개(오행 색, 한자 함께), 조건 칩, 이름 카드(NameWithHanja, 등급 배지, 뜻 한 줄, 흔한 정도, 저장 하트), 1위만 바다색 테두리, "이름 더 보기", "같은 조건으로 다른 이름 보기", 아래에 리포트 안내.
- 리포트 안내: 모래 테두리 NameCardFrame 이름 칸(이름 + 등급 배지), "이미 무료로 받은 것", "리포트에 더 들어가는 것", "받은 날의 내용 그대로 보관돼요", "같은 아이, 같은 이름이면 다시 결제하지 않아요", 주 버튼 "리포트 받기", 보조 "무료 결과 계속 보기"(깎아내리는 문구 금지), 환불 기준 링크.
- 완료: PebbleFrame 이름 카드, "리포트가 준비됐어요", "PDF 받기", 다음 할 일(돌·백일 이름 카드 만들기, 가족에게 이름 보내기 · 생년월일은 빠져요).
- 공유 이름 카드(next/og)와 PDF의 이름도 NameWithHanja 규칙(한자 가운데 정렬)으로 맞춰 줘. 단, PDF는 결제한 리포트의 내용(스냅숏)이 바뀌면 안 되니까 모양만 바꾸고, 손대기 전에 어떻게 할지 먼저 알려 줘.

끝나면 화면별로 바뀐 점과 확인이 필요한 것을 알려 줘.
```

## 남은 결정 (사장님 확인)

- 상세 리포트 가격
- 무료 범위가 시안과 같은지 (1·2단계 결과 보고 확인)
- 대표자명, 사업자등록번호 (사업자 등록 후)
- 대법원 이름 통계 자료가 들어오면 통계 구역 숫자 채우기
