실험 지점 넣는 법 (`hybrid.ts`용, 시험 후 `git checkout lib/naming/recommend.ts`로 되돌린다):
`recommendNames`의 외자 반복문 앞에 아래를 넣고, 외자·두 글자 반복문의 `trendScore(...)` 호출을 `__t(eum)` / `__t(eumA + eumB)`로 바꾼다.
```ts
const __adj = (globalThis as { __SOUND_ADJ?: (given: string, t: number, minTrend: number) => number }).__SOUND_ADJ;
const __t = (given: string) => {
  const t = trendScore(given, allowSyllables);
  return __adj && t >= 0 ? __adj(given, t, minTrend) : t;
};
```
