# 성씨 한자 자료

- 출처: 통계청, 「2015 인구주택총조사」 성씨·본관별 인구 (5인 이상, 전국). KOSIS 국가통계포털(kosis.kr)에서 2026-10-24 내려받음.
- 파일: `성씨ㆍ본관별_인구_5인_이상___전국_20261024225915.csv` (UTF-8). 성씨 합계 행(`"이(李)",7306828`) 뒤에 그 성씨의 본관 행이 이어진다.
- 쓰는 곳: `scripts/build-surname-table.ts`가 성씨 합계 행만 읽어 `lib/naming/surname-table.ts`(성씨 한자 표)를 만든다. 입력 폼의 성씨 한자 후보와 서버의 성씨 한자 확인에 쓴다 (`lib/naming/surname-hanja.ts`).
- 다시 만들기: `npx tsx --env-file=.env.local scripts/build-surname-table.ts` (획수는 `hanja_dict`에서 읽는다).
- 읽을 때 고친 것: `제갈(諸*)` → 諸葛(자료에서 葛이 깨짐), 호환 한자는 NFC로 표준 글자에 합침(李 두 행), `기타(기타)` 행은 뺌. 사전에 없는 글자(간체자 罗·卢·赵 등 23자)와 사전에 그 소리 읽기가 없는 글자(鴌·肖·薫)는 표에서 뺀다.
